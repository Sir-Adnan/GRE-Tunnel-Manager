# Tunnel Admin

Operators manage ports and server links on desktop and mobile, in Persian RTL or English LTR. Keep common actions visible: add, inspect, edit, select and delete. Use a quiet sidebar, a compact server header, readable tables and review before apply. Poppins and Geist serve English; Vazirmatn serves Persian without letter spacing; JetBrains Mono keeps endpoints readable. Local fonts, restrained borders, semantic tokens and short reduced-motion-aware transitions. Nettinx is the original user-selected default palette; its documented contrast limitations are deliberately preserved. Appearance never changes capabilities or permissions.
