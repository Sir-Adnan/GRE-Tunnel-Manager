# Third-party notices

The panel embeds a built frontend. Relevant license notices are included in `LICENSES/` and distributed with release packages. React/React DOM, Radix primitives, Lucide icons, class-variance-authority, cn, Recharts and its dependencies, Vazirmatn and JetBrains Mono retain their respective licenses and ownership. The chart dependency notices are collected in `LICENSES/ChartDependencies.txt`. Historical font notices are retained for compatibility. Exact dependency versions are locked in `web/package-lock.json` and `go.sum`.

shadcn/ui component sources were generated with its official CLI (MIT, https://github.com/shadcn-ui/ui). The appearance-selection boundary was adapted from the user-supplied Visual Experience System skill. The default Nettinx Design System preset was explicitly selected by the user: https://tweakcn.com/themes/cmqbb3gdw000104l29dvzaqja. Original palette values and provenance are retained in `web/src/experience/sources/nettinx.json`; no license grant for the community preset is inferred from tweakcn's software license.

Go's standard library and golang.org/x modules retain their BSD-style licenses. No Go or Node installation is included or required at server runtime.
