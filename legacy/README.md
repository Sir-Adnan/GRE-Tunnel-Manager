# GRE Tunnel Manager — Legacy v13.9

نسخهٔ قدیمی پروژه، برای نگهداری تاریخچه و مراجعه به منوی قبلی. کدهای این پوشه به همان شکل قدیمی باقی مانده‌اند؛ توسعهٔ نسخهٔ فعلی در [ریشهٔ پروژه](../README.md) انجام می‌شود.

| فایل | توضیح |

| [gre-stable.sh](gre-stable.sh) | نسخهٔ منجمد v13.6، برای نصب‌های قدیمی |

## دریافت و اجرا

اگر به‌طور مشخص نسخهٔ **قدیمی v13.9** را می‌خواهید، از مسیر `legacy/gre.sh` دریافت کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/Sir-Adnan/GRE-Tunnel-Manager/main/legacy/gre.sh -o gre-legacy.sh && sudo bash gre-legacy.sh
```

برای کاربر root، `sudo` را حذف کنید. این فرمان فایل را در پوشهٔ فعلی ذخیره می‌کند. مسیر `main/gre.sh` مربوط به نسخهٔ جدید است و نسخهٔ قدیمی را اجرا نمی‌کند.

**نکتهٔ میان‌بر:** آدرس دانلود داخل اسکریپت قدیمی همچنان به `main/gre.sh` اشاره دارد. نصب یا به‌روزرسانی میان‌بر `igre` از منوی قدیمی ممکن است نسخهٔ جدید را دریافت کند. برای اجرای همین بایگانی، از `sudo bash gre-legacy.sh` استفاده کنید.

## ساخت GRE

1. روی سرور خارج، **1: Kharej Server** را انتخاب کنید و IP سرور ایران را بدهید.
2. روی سرور ایران، **2: Iran Server** را انتخاب کنید و IP سرور خارج را بدهید.
3. در هر دو سمت Tunnel ID یکسان، مثلاً `10`، وارد کنید. برای MTU پیش‌فرض Enter بزنید.

در این مثال، IP داخل تونل در سمت خارج `10.0.10.1` و در سمت ایران `10.0.10.2` است. از سمت ایران با `ping 10.0.10.1` بررسی کنید. نام‌های خارج و ایران نقش دو سمت هستند؛ سرورها می‌توانند در کشورهای دیگر هم باشند.

## منوی قدیمی

| شماره | گزینه | کاربرد |
| --- | --- | --- |
| 1 | Kharej Server | ساخت GRE، سمت خارج |
| 2 | Iran Server | ساخت GRE، سمت ایران |
| 3 | Delete Tunnel | حذف GRE |
| 4 | Edit Config | ویرایش دستی سرویس GRE |
| 5 | Re-install Shortcut | نصب مجدد میان‌بر؛ توضیح بالا را بخوانید |
| 6 | Refresh Stats | تازه‌سازی اطلاعات سرور |
| 7 | Simple GRE IPv4 | GRE همراه با پورت‌مپینگ ساده |
| 8 | Delete Simple | حذف Simple GRE |
| 9 | Adv. Forwarding | افزودن فوروارد پورت |
| 10 | Edit Forwarding | ویرایش دستی قوانین فوروارد |
| 11 | Del Forwarding | حذف قانون فوروارد |
| 12 | WIPE ALL | پاک‌سازی Simple GRE و فورواردهای قدیمی |
| 13 | Realm Manager | مدیریت Realm |
| 14 | Performance | تنظیمات سراسری شبکه |
| 0 | Exit | خروج |

برای مثال، در گزینهٔ ۹، `Local Port = 443`، `Dest Tunnel IP = 10.0.10.1` و `Dest Port = 443` یعنی انتقال پورت ۴۴۳ این سرور به پورت ۴۴۳ سمت دیگر تونل.

## نکات نسخهٔ قدیمی

- Linux با systemd و دسترسی root لازم است. برای GRE، پروتکل شمارهٔ ۴۷ باید در مسیر و فایروال مجاز باشد؛ GRE رمزنگاری ندارد.
- v13.7 و بالاتر از GRE دارای key استفاده می‌کنند. v13.6 بدون key است؛ دو سمت را از این دو نسل متفاوت نسازید.
- پروفایل Performance و برخی عملیات قدیمی، تنظیمات مشترک میزبان را تغییر می‌دهند و سازوکار ثبت مقدار قبلیِ نسخهٔ جدید را ندارند. تعداد کاربر یا ظرفیت مشخصی تضمین نمی‌شود.
- رفع باگ‌ها، حذف گروهی جدید، تنظیمات HAProxy و روش‌های جدید تونل در این بایگانی وجود ندارند. برای آن‌ها [نسخهٔ فعلی](../README.md) را ببینید.

مستندات داخل `legacy/docs` تاریخی‌اند و باید همراه کد همین نسخه خوانده شوند.
