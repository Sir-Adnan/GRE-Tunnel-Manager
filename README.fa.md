# مدیریت تونل و پورت فوروارد

**سرورها را وصل کنید، پورت‌ها را انتقال دهید و مدیریت را ساده نگه دارید.**

پروژهٔ **GRE Tunnel Manager**

زبان: **فارسی** · [نسخهٔ انگلیسی](README.md)

راهنماها: [شروع کار](#شروع-کار) · [وب‌پنل](#web-panel) · [مستندات فنی](docs/README.md) · [تغییرات نسخه‌ها](docs/CHANGELOG.md)

با این پروژه می‌توانید تونل‌ها و فوروارد ترافیک را از منوی ترمینال یا وب‌پنل مدیریت کنید. بسته به نیازتان، پورت‌ها را مستقیم فوروارد کنید، ابتدا بین سرورها تونل GRE بسازید یا از اتصال معکوس استفاده کنید. هر روش، منوی مخصوص خودش را دارد.

## شروع کار

روی سرور **دبیان یا اوبونتو با systemd**، این دستور را اجرا کنید:

```bash
curl -fsSL --ipv4 https://raw.githubusercontent.com/Sir-Adnan/GRE-Tunnel-Manager/main/gre.sh -o gre.sh && sudo bash gre.sh
```

اگر با کاربر **root** وارد شده‌اید، بخش `sudo` را بردارید. برای اجرای دوباره، از همان پوشه دستور `sudo bash gre.sh` را بزنید. اگر ابزار curl نصب نیست، ابتدا دستور `sudo apt-get update && sudo apt-get install -y curl` را اجرا کنید. برای سروری که فقط IPv6 دارد، گزینهٔ `--ipv4` را بردارید.

از منو، بخش **GRE Tunnel**، **Port Forwarding**، **HAProxy**، **Realm** یا **Reverse Tunnel** را انتخاب کنید. در ساخت فوروارد، پورت ورودی، آی‌پی مقصد و پورت مقصد را وارد می‌کنید و پیش از اعمال، تنظیمات را می‌بینید. نام دلخواه اختیاری است؛ می‌توانید چند پورت مثل `443,8443` یا بازهٔ `8000-8003` را هم‌زمان بسازید.

## انتخاب روش اتصال

| روش | کاربرد |
| --- | --- |
| فوروارد با **iptables / nftables** | انتقال ترافیک TCP و UDP در کرنل لینوکس، بدون اجرای دائمی خود مدیر |
| تونل **GRE / ip6gre** | ساخت ارتباط شبکه بین دو سرور؛ در صورت نیاز با فوروارد جداگانه |
| تونل **HAProxy** | انتقال ترافیک TCP، بررسی سلامت مقصد، لودبالانس و مقصد پشتیبان |
| تونل **Realm** | انتقال ترافیک TCP و UDP و توزیع بین چند مقصد |
| اتصال معکوس **FRP / rathole** | برقراری ارتباط از سمت مقصد؛ با روش‌های انتقال FRP یا رمزنگاری Noise در rathole |

برای فوروارد مستقیم، نیازی به GRE ندارید. برای انتقال ترافیک وایرگارد یا AmneziaWG، روشی را انتخاب کنید که UDP داشته باشد؛ بخش HAProxy این پروژه برای TCP است. خود GRE رمزنگاری ندارد و شبکه باید پروتکل شمارهٔ 47 را عبور دهد.

## وب‌پنل

برای مدیریت از مرورگر، این دستور را اجرا کنید یا در ترمینال، **گزینهٔ 8 · Web Panel** را بزنید:

```bash
curl -fsSL --ipv4 https://raw.githubusercontent.com/Sir-Adnan/GRE-Tunnel-Manager/main/panel-install.sh -o panel-install.sh && sudo bash panel-install.sh --quick
```

پس از نصب، آدرس دسترسی نمایش داده می‌شود. پورت انتخاب‌شده را در فایروال سرور و ارائه‌دهنده باز کنید و آدرس را در مرورگر وارد کنید. برای گواهی اولیهٔ HTTPS، اثر انگشت نمایش‌داده‌شده را از طریق SSH بررسی کنید و بعد به آن اعتماد کنید.

محیط پنل فارسی و انگلیسی است و روی موبایل و دسکتاپ کار می‌کند. حالت روشن و تیره، مدیریت اتصال‌ها و ثبت اختیاری مصرف ترافیک در دسترس‌اند. پنل یک فایل اجرایی آمادهٔ Go است و رابط کاربری را همراه خودش دارد؛ **روی سرورها به نصب Node.js، پایتون، کامپایلر Go یا سرور پایگاه داده نیازی نیست**. ترافیک تونل از موتور انتخابی عبور می‌کند و به بازبودن پنل وابسته نیست.

**نسخهٔ v1.3.1** نصب سریع با HTTP یا HTTPS، نود و ایجنت، مسیریابی پیشرفته، دوره‌های مصرف، مشاهده و ویرایش کانفیگ و پروفایل‌های اتصال را دارد. نصب سریع آی‌پی را تشخیص می‌دهد، پورت آزاد انتخاب می‌کند و اطلاعات ورود ساخته‌شده را یک بار نشان می‌دهد. برای پورت یا دامنهٔ دلخواه و انتخاب HTTP، [راهنمای نصب](docs/WEB-PANEL.md#quick-and-custom-setup) را ببینید.

## مدیریت چند سرور

می‌توانید فقط سرور فعلی را مدیریت کنید، پنل را روی یکی از سرورهای ورودی یا خروجی نصب کنید یا سرور جداگانه‌ای برای مدیریت داشته باشید. سرورهای دیگر با ایجنت اختیاری به پنل وصل می‌شوند. خود سرور پنل هم از ابتدا به‌عنوان نود محلی نمایش داده می‌شود؛ داشتن سرور سوم اجباری نیست.

در پنل، مشاهدهٔ امن موجودی سرورها، ساخت هماهنگ GRE و FRP و گزارش اختیاری مصرف نودها پشتیبانی می‌شود. فرم‌های عمومی ویرایش تونل همچنان روی سرور خود پنل عمل می‌کنند. [راهنمای نود و ایجنت](docs/NODES.md)
