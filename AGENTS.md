# AGENTS.md

## Project

Bash-based Linux tunnel and forwarding manager. Runtime code lives in `src/`; `gre.sh` is generated by `tools/build.py`. Python is used for development and tests, not required on managed servers.

## Making changes

- Read the relevant modules and documentation before editing. See `docs/ARCHITECTURE.md` for module boundaries and `docs/ARTIFACTS.md` for resources created on servers.
- Edit `src/`, then run `python3 tools/build.py`. Do not edit generated `gre.sh` directly.
- Keep changes focused and modular. Separate terminal interaction, configuration validation/rendering, and system operations.
- Preserve existing configurations and network compatibility unless the task explicitly requires a migration. Keep `gre-stable.sh` and archived scripts in `legacy/` unchanged unless requested.

## Code quality

- Validate external input before using it in commands or generated configuration. Use quoted variables, command arrays, and checked exit statuses; never evaluate configuration as shell code.
- For managed-state changes, use the existing lock, reload the complete state, and preserve unrelated records. UI filters must not become the state being saved.
- Modify only resources owned by the manager. Use existing backup/recovery paths and report partial failures; never flush the host firewall or conntrack table.
- Keep prompts short, defaults clear, and optional settings off the normal setup path. Avoid dependencies or background services unrelated to the requested feature.

## Verification and documentation

- Run `python3 tools/build.py --check` and `python3 -m unittest discover -s tests -v`.
- Run ShellCheck for the modern modules listed in `.github/workflows/checks.yml` and `git diff --check`.
- For networking changes, run `sudo bash tests/linux_namespace.sh` in its isolated namespaces. Distinguish local tests from checks that still require real servers.
- Update affected guides and `docs/CHANGELOG.md` when behavior changes. Keep `README.md` and `README.fa.md` consistent; Persian prose starts with Persian words and commands remain left-to-right.
