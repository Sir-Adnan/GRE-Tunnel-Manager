# ظاهر و راهنمای ترمینال

[بازگشت به شروع سریع](../README.md)

## برنامه کجا باز می‌شود؟

رابط GRE Tunnel Manager در همان پنجرهٔ SSH اجرا می‌شود. اجرای دستور، منوی ترمینال را باز می‌کند؛ پورت وب یا صفحهٔ مرورگر ساخته نمی‌شود. گزینه را با **شماره و Enter** انتخاب کنید.

نمونهٔ HTML اولیه یک طرح تعاملی برای بررسی چیدمان بود. رابط فعلی در خود ترمینال اجرا می‌شود: منوی اصلی کوتاه است و GRE، فوروارد، HAProxy و Realm بخش‌های مشخص دارند. هر بخش گزینه‌های افزودن، نمایش و حذف خودش را دارد. هدر، کادرها و رنگ‌ها هم در Bash پیاده شده‌اند؛ برای انتخاب، شماره و Enter بزنید.

## دریافت نسخهٔ جدید

اگر فقط منوی سادهٔ `v1.2.0` را می‌بینید، همان نسخهٔ قبلی اجرا شده است. فایل را دوباره دریافت و شمارهٔ نسخه را بررسی کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/Sir-Adnan/GRE-Tunnel-Manager/main/gre.sh -o gre.sh
bash gre.sh --version
sudo bash gre.sh --theme dark --layout guided
```

برای کاربر root، `sudo` را حذف کنید. فایل `gre.sh` در پوشهٔ فعلی جایگزین می‌شود؛ تنظیمات اتصال‌ها در مسیر جداگانهٔ مدیر باقی می‌مانند. اگر از میان‌بر `igre` استفاده می‌کنید، فایل دانلودشده و میان‌بر دو کپی جدا هستند؛ برای به‌روزرسانی میان‌بر، **Settings & Tools → Install / update igre** را اجرا کنید و سپس دوباره `igre` را باز کنید.

## تم، رنگ و چیدمان

در منوی اصلی **7: Settings & Tools → Appearance & language** را باز کنید:

| گزینه | انتخاب‌ها |
| --- | --- |
| Theme | `dark`، `light`، `plain` |
| Accent | `ocean`، `violet`، `emerald`، `amber` |
| Help language | `en`، `finglish`، `fa` |
| Test Farsi display | بررسی خوانایی حروف فارسی |
| Layout | `guided` با توضیح کوتاه، `compact` فقط با نام گزینه‌ها |

تنظیمات انتخاب‌شده از منو ذخیره می‌شوند. انتخاب‌های خط فرمان فقط برای همان اجرا هستند:

```bash
sudo bash gre.sh --theme light --layout guided --language finglish
sudo bash gre.sh --theme plain --layout compact
```

رنگ اصلی از منوی **Accent** انتخاب می‌شود. گزینهٔ `--accent` وجود ندارد.

## رنگ‌ها یا کادرها درست نیستند

- با یک ترمینال دارای پشتیبانی ANSI و UTF-8 مانند Windows Terminal یا ترمینال سیستم خود به سرور SSH بزنید. در ترمینال‌های فاقد UTF-8، کادر سادهٔ ASCII استفاده می‌شود.
- عرض حدود **۸۰ ستون یا بیشتر** برای دیدن عنوان و توضیح در یک ردیف مناسب است. در پنجره‌های باریک، توضیح کوتاه یا جدا می‌شود؛ انتخاب‌ها با شماره باقی می‌مانند.
- Dark و Light، پس‌زمینهٔ کادرهای خود برنامه را تغییر می‌دهند؛ کل پنجره، فونت و رنگ پس‌زمینهٔ برنامهٔ SSH در تنظیمات ترمینال شما تعیین می‌شود.
- با `printf '%s\n' "$TERM"` نوع ترمینال را ببینید. مقدار `dumb` یا متغیر `NO_COLOR` رنگ‌ها را غیرفعال می‌کند. نوع ترمینال را مطابق قابلیت واقعی برنامهٔ SSH تنظیم کنید؛ تغییر نام آن، قابلیت جدید ایجاد نمی‌کند.
- خروجی ذخیره‌شده در فایل یا pipe به‌صورت ساده و بدون رنگ تولید می‌شود. برای رنگ‌ها برنامه را مستقیم در ترمینال اجرا کنید.
- اگر رنگ‌ها ناخوانا هستند، `--theme plain` همهٔ رنگ‌ها را خاموش می‌کند. برای ترمینال کوچک، `--layout compact` را هم انتخاب کنید.

فارسی فقط برای راهنماهای مستقل است. نمایش راست‌به‌چپ به ترمینال بستگی دارد؛ اگر حروف جدا یا نامرتب‌اند، Finglish را انتخاب کنید. IP، پورت، فرمان‌ها و عنوان‌ها انگلیسی می‌مانند.

## پیش‌نمایش بدون تغییر شبکه

```bash
bash gre.sh --preview home --theme dark --layout guided
bash gre.sh --demo --language finglish
```

این حالت‌ها به root نیاز ندارند. `DEMO` فقط در همین حالت‌ها نمایش داده می‌شود و به معنی آزمایشی‌بودن نسخهٔ عادی برنامه نیست. پنل هیچ سرویس دائمی یا وابستگی جدیدی به Python، Node.js یا ابزارهای TUI اضافه نمی‌کند؛ تشخیص اختیاری اندازه و رنگ از `tput` استفاده می‌کند و جایگزین داخلی دارد.
