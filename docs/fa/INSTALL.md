# نصب، به‌روزرسانی و حذف

[English](../INSTALL.md) · **فارسی**

هرچه برای نصب پنل روی سرور لازم است، در یک صفحه. راهنمای امکانات در [فهرست راهنماها](README.md) است.

## پیش‌نیازها

- دبیان یا اوبونتو با systemd، روی x86_64 یا arm64، با کاربر root (یا `sudo`).
- حدود 6 مگابایت دانلود. چیزی کامپایل نمی‌شود: نصب‌کننده نسخهٔ آماده را دانلود و checksum آن (SHA-256) را بررسی می‌کند. Node.js، پایتون، داکر یا پایگاه داده نصب نمی‌شود.
- یک پورت TCP آزاد برای پنل. برای گواهی معتبر، پورت 80 باید چند ثانیه از اینترنت به سرور برسد (یا برای دامنه از DNS کلودفلر استفاده کنید).

## نصب یک‌خطی

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/Sir-Adnan/GRE-Tunnel-Manager/main/install.sh)"
```

نصب‌کننده هر مرحله را نشان می‌دهد: دانلود با نوار پیشرفت، بررسی checksum، و بعد یک راه‌اندازی کوتاه که این‌ها را می‌پرسد:

1. **آدرس:** آی‌پی عمومی سرور (خودکار پیدا می‌شود) یا دامنه‌ای که به آن اشاره می‌کند.
2. **امنیت:** HTTPS با Let's Encrypt (معتبر و با تمدید خودکار)، HTTPS خودامضا، یا HTTP ساده.
3. **پورت:** خالی بگذارید تا یک پورت آزاد تصادفی انتخاب شود.
4. **نام کاربری و رمز:** رمز قوی می‌تواند ساخته شود و فقط یک بار در پایان نشان داده می‌شود.
5. **موتورها:** iptables، nftables، HAProxy، Realm، FRP و rathole همین حالا نصب شوند یا بعداً از پنل.

پنل بالا می‌آید و خلاصهٔ پایانی آدرس و اطلاعات ورود را نشان می‌دهد. پورت پنل را در فایروال سرور و فایروال ارائه‌دهنده باز کنید و وارد شوید. دکمهٔ Esc پیش از هر تغییری راه‌اندازی را لغو می‌کند.

`curl -fsSL …/install.sh | sudo bash` هم کار می‌کند و نصب‌کننده سؤال‌ها را در همان ترمینالی می‌پرسد که sudo را از آن اجرا کرده‌اید.

## نصب بدون سؤال

گزینه‌ها را بعد از `@` بنویسید (`@` جای نام اسکریپت می‌نشیند). هر گزینه جواب سؤال خودش است و `--yes` بقیه را با پیش‌فرض پر می‌کند.

| می‌خواهم | دستور |
| --- | --- |
| پیش‌فرض: HTTPS معتبر برای آی‌پی، پورت تصادفی، رمز ساخته‌شده | `sudo bash -c "$(curl -fsSL URL)" @ --yes` |
| **HTTP** با پورت و نام کاربری و رمز دلخواه | `sudo bash -c "$(curl -fsSL URL)" @ --http --port 8080 --user admin --password 'my-long-password' --yes` |
| HTTPS برای دامنهٔ من | `sudo bash -c "$(curl -fsSL URL)" @ --domain panel.example.com --port 2053 --yes` |
| HTTPS دامنه با DNS کلودفلر (بدون پورت 80) | `sudo bash -c "$(curl -fsSL URL)" @ --domain panel.example.com --cloudflare-token-file /root/cf.token --yes` |
| HTTPS خودامضا | `sudo bash -c "$(curl -fsSL URL)" @ --self-signed --port 2053 --yes` |
| همه‌چیز به‌همراه همهٔ موتورهای تونل | `--engines` را اضافه کنید |

`URL` همان `https://raw.githubusercontent.com/Sir-Adnan/GRE-Tunnel-Manager/main/install.sh` است.

رمزی که در خط فرمان بنویسید در تاریخچهٔ شل می‌ماند. برای جلوگیری، آن را در یک متغیر بگذارید:

```bash
read -rs PANEL_PASS && export PANEL_PASS
sudo --preserve-env=PANEL_PASS bash -c "$(curl -fsSL URL)" @ --http --port 8080 --password-env PANEL_PASS --yes
```

رمز باید دست‌کم 8 کاراکتر (و حداکثر 72 بایت) باشد. فقط هش bcrypt آن ذخیره می‌شود.

### همهٔ گزینه‌ها

| گزینه | معنی |
| --- | --- |
| `--domain NAME` | دامنه یا آی‌پی پنل؛ پیش‌فرض: آی‌پی عمومی شناسایی‌شده |
| `--port N` | پورت TCP؛ پیش‌فرض: یک پورت آزاد تصادفی |
| `--user NAME` | نام کاربری؛ پیش‌فرض `admin` |
| `--password VALUE` · `--password-env VAR` | رمز ورود، یا متغیری که رمز در آن است؛ پیش‌فرض: ساخته می‌شود |
| `--https` · `--self-signed` · `--http` | Let's Encrypt (پیش‌فرض)، گواهی خودامضا، یا بدون رمزنگاری |
| `--email ADDRESS` | ایمیل اختیاری برای Let's Encrypt |
| `--cloudflare-token-file FILE` | تأیید دامنه با DNS کلودفلر به‌جای پورت 80 |
| `--staging` | سرور آزمایشی Let's Encrypt، برای تست |
| `--listen IP` | آدرس محلی برای گوش دادن؛ پیش‌فرض: همهٔ آدرس‌های IPv4 |
| `--engines` | همهٔ موتورهای تونل هم نصب شوند |
| `--no-update-check` | بررسی روزانهٔ نسخهٔ جدید در گیت‌هاب خاموش باشد |
| `--yes` | هیچ سؤالی نپرس؛ پیش‌فرض‌ها را بگذار |
| `--agent [--operations] [--traffic]` | به‌جای پنل، [ایجنت](../NODES.md) خروجی نصب شود |
| `--remove` | پنل حذف شود؛ تونل‌ها کار می‌کنند |
| `--version X.Y.Z` · `--package-dir DIR` | نسخهٔ دیگر، یا آرشیو محلی همراه `SHA256SUMS` (آفلاین) |

روی سروری که پنل از قبل دارد، گزینه‌های راه‌اندازی نادیده گرفته می‌شوند و آدرس، پورت، اطلاعات ورود و گواهی حفظ می‌شوند. برای تغییر آن‌ها از `gtm` استفاده کنید.

## بعد از نصب: `gtm`

<div dir="ltr" align="left">

```bash
sudo gtm                 # status and a menu
sudo gtm password        # new login password
sudo gtm port 2053       # move the panel; a failed start restores the old port
sudo gtm https issue     # get (or retry) a trusted certificate
sudo gtm logs -f         # follow the panel log
sudo gtm 2fa off         # turn two-factor sign-in off
```

</div>

- `sudo gtm`: وضعیت سرویس‌ها، آدرس، گواهی و نسخه، به‌همراه منو.
- `sudo gtm password`: رمز جدید؛ همهٔ ورودها خارج می‌شوند.
- `sudo gtm port 2053`: تغییر پورت پنل؛ اگر بالا نیاید، پورت قبلی برمی‌گردد.
- `sudo gtm https issue`: گرفتن (یا تلاش دوباره برای) گواهی معتبر.
- `sudo gtm logs -f`: دنبال کردن لاگ پنل.
- `sudo gtm 2fa off`: اگر برنامهٔ احراز هویت گم شد، ورود دومرحله‌ای خاموش می‌شود.

فهرست کامل دستورها در [خط فرمان](../COMMAND-LINE.md) (انگلیسی) است.

## به‌روزرسانی

از پنل: **تنظیمات ← به‌روزرسانی ← به‌روزرسانی**. روی سرور:

```bash
sudo gtm update
```

نسخهٔ جدید پیش از توقف هر سرویسی بررسی می‌شود و اگر بالا نیاید، نسخهٔ قبلی برمی‌گردد. تونل‌ها در طول به‌روزرسانی کار می‌کنند. اجرای دوبارهٔ نصب‌کننده هم نصب خراب را تعمیر می‌کند و تنظیمات را نگه می‌دارد.

## حذف

```bash
sudo gtm remove
```

فهرست چیزهایی که حذف یا حفظ می‌شوند را نشان می‌دهد و می‌خواهد `REMOVE` را تایپ کنید. فقط پنل حذف می‌شود؛ تونل‌ها، فورواردها و موتورها کار می‌کنند. جزئیات در [حذف پنل](../PANEL-REMOVAL.md) (انگلیسی).

## ارتقا از نسخه‌های قدیمی

- **v1.5.x و بعد:** `sudo gtm update` (از v1.6.0) یا همان دستور نصب یک‌خطی. اطلاعات ورود، گواهی، اتصال‌ها و نودها حفظ می‌شوند.
- **اسکریپت‌های v13.x:** پنل را نصب کنید و بعد اسکریپت فوروارد قدیمی، Simple GRE و فایل‌های تنظیم قدیمی را طبق [کنار گذاشتن نصب‌های قدیمی](../RETIRING-OLD-INSTALLS.md) (انگلیسی) حذف کنید. تونل‌های قدیمی `gre-tun-N` کار می‌کنند و در پنل دیده می‌شوند.
- `panel-install.sh` و `node-install.sh` هنوز گزینه‌های قدیمی را می‌پذیرند و نصب‌کنندهٔ جدید را صدا می‌زنند.
