# HTTPS و گواهی پنل

[English](../HTTPS.md) · **فارسی**

پنل گواهی خود را از یکی از این سه منبع می‌گیرد:

| منبع | مورد اعتماد مرورگر | تمدید | راه‌اندازی |
| --- | --- | --- | --- |
| **Let's Encrypt** (داخلی، پیش‌فرض نصب) | بله | خودکار با تایمر systemd | نصب‌کننده، **تنظیمات ← امنیت و دسترسی** یا `gtm https issue` |
| **کلاینت ACME بیرونی** (Certbot، acme.sh) | بله | با برنامهٔ خود کلاینت | `gtm-panel certificate install` از هوک کلاینت |
| **خودامضا** (`--self-signed` یا جایگزین خودکار) | خیر؛ اثر انگشت را مقایسه کنید | ندارد (یک‌ساله) | نصب‌کننده، تنظیمات یا `gtm https self-signed` |

درخواست یا تمدید گواهی هیچ‌وقت تونل‌ها را قطع نمی‌کند. اگر گواهی جدید گرفته نشود، گواهی فعلی سر جایش می‌ماند.

## Let's Encrypt داخلی

```bash
sudo gtm https issue --domain panel.example.com --email you@example.com
```

- **دامنه یا آی‌پی عمومی:** بدون `--domain` آدرس فعلی پنل استفاده می‌شود. آی‌پی گواهی شش‌روزه می‌گیرد و دامنه گواهی 90 روزه.
- **تأیید با پورت 80 (پیش‌فرض):** پورت 80 فقط چند ثانیه باز می‌شود. باید در فایروال سرور و ارائه‌دهنده باز باشد و به سرور دیگری فوروارد نشده باشد. اگر سرویس دیگری روی 80 است، آن را کوتاه متوقف کنید یا از DNS استفاده کنید.
- **تأیید با DNS کلودفلر (فقط دامنه):** پورتی باز نمی‌شود. یک API Token با دسترسی **Zone → Read** و **Zone → DNS → Edit** بسازید، در فایلی که فقط root می‌خواند بگذارید و یک بار بدهید:

  ```bash
  sudo gtm https issue --domain panel.example.com --cloudflare-token-file /root/cloudflare.token
  ```

  پنل یک نسخهٔ خصوصی برای تمدید نگه می‌دارد و فایل اصلی را بعد از آن می‌توانید پاک کنید.
- **پنل HTTP:** همین دستور پنل را به HTTPS می‌برد؛ بعد با آدرس `https://` دوباره وارد شوید.
- **تست:** `--staging` از سرور آزمایشی Let's Encrypt استفاده می‌کند (گواهی نامعتبر، محدودیت کمتر).

در پنل هم از **تنظیمات ← امنیت و دسترسی ← گرفتن گواهی معتبر** همین کار با پورت 80 انجام می‌شود. تأیید DNS کلودفلر فقط از ترمینال است تا توکن هرگز از مرورگر رد نشود.

## تمدید

تایمر `gre-manager-panel-certificate.timer` هر شش ساعت بررسی می‌کند و گواهی را در یک‌سوم پایانی عمرش تمدید می‌کند: برای دامنه حدود 30 روز و برای آی‌پی حدود دو روز پیش از انقضا.

```bash
sudo gtm https renew --force                      # تمدید همین حالا
systemctl list-timers gre-manager-panel-certificate.timer
journalctl -u gre-manager-panel-certificate.service
```

اگر آدرس عمومی پنل عوض شود، تمدید با توضیح متوقف می‌شود؛ برای آدرس جدید دوباره `gtm https issue` بزنید.

## کلاینت ACME بیرونی

برای ارائه‌دهنده‌های DNS دیگر یا وقتی Certbot و acme.sh از قبل گواهی‌ها را مدیریت می‌کنند، هوک کلاینت هر گواهی جدید را به پنل می‌دهد:

```bash
sudo gtm-panel certificate install --cert FULLCHAIN.pem --key PRIVKEY.pem --host panel.example.com
```

این دستور کلید و نام و زنجیره را بررسی و پنل را بی‌وقفه بارگذاری می‌کند و تمدید داخلی را خاموش می‌کند تا دو کلاینت با هم رقابت نکنند. نمونهٔ هوک Certbot و acme.sh در [نسخهٔ انگلیسی](../HTTPS.md#external-acme-client) آمده است.

## وضعیت و بازیابی

- **تنظیمات ← امنیت و دسترسی** گواهی فعلی (نام، صادرکننده، اثر انگشت، انقضا) و وضعیت تمدید را نشان می‌دهد.
- `sudo gtm https` خلاصهٔ گواهی و گزینه‌ها را نشان می‌دهد.
- `sudo gtm https self-signed` به گواهی خودامضای جدید برمی‌گردد و تمدید داخلی را خاموش می‌کند.
